1. **Abrir a app** — `npm run dev:client` e ir a http://localhost:5002
2. **Dashboard** — Ver métricas, funnel, alertas e Kanban (com dados de demo)
3. **Nouveau devis** — Preencher formulário, gerar PDF, "Ajouter au pipeline"
4. **Um projeto** — Clicar num card, ver stepper, notas, "Planifier visite", WhatsApp

Se tudo isto funcionar no teu browser, a demo está boa para mostrar.

## Como ter impacto por email

### O que enviar

- **Opção A (melhor):** Link para **demo em linha** (ex. Vercel, Netlify, Replit) + link para **repositório** (GitHub). Quem recruta abre a app em 1 clique e, se quiser, vê o código.
- **Opção B:** Só **link para o repositório** com README muito claro: "Demo Luxembourg — consola de operações para instaladores solares. Para ver a app: clone, `npm install`, `npm run dev:client`, abrir http://localhost:5002."
- **Opção C:** Repo + **vídeo curto** (1–2 min) no YouTube ou Loom: "Isto é o que construí: em 30 segundos vês…" e mostras dashboard → devis → PDF → pipeline.

### Assunto e primeiras linhas do email

- **Assunto:** Curto e concreto, ex.:  
  "Candidatura [função] — Demo SolarOps Luxembourg (consola de operações)"
- **Primeiro parágrafo:** Uma frase sobre ti + uma sobre o projeto, ex.:  
  "Sou [nome], candidato/a à vaga de [função]. Para mostrar o que consigo fazer em Operations & Digital, construí uma MVP de consola de operações para instaladores solares no Luxemburgo: devis em 5 minutos, pipeline Kanban, alertas CREOS e checklist por projeto. Pode ver a demo aqui: [LINK]."
- **Segundo parágrafo:** O que eles ganham em abrir o link:  
  "Em 30 segundos vê-se o valor: leads, pipeline, gargalos e um PDF de devis com Klimabonus. O repositório está em [LINK] com instruções no README."

### O que dá impacto

1. **Link que abre logo** — Demo em linha > "descarregue e corra localmente" (a não ser que a vaga seja muito técnica e queiram ver o repo).
2. **Uma frase de valor** — "Consola de operações para instaladores no Luxemburgo: devis em 5 min, pipeline, CREOS, Klimabonus."
3. **Pedir uma ação clara** — "Quando tiver 2 minutos, abra a demo; depois podemos falar do próximo passo."
4. **README impecável** — Quem abre o repo vê logo: o que é, como correr, que é para Luxemburgo e que pode ser adaptado (secção "Para outra empresa ou região").

### Se não tiveres ainda deploy em linha

- No email: "A demo está no repositório; em 2 minutos pode clonar e correr com `npm install` e `npm run dev:client` (instruções no README)."
- Para máximo impacto, considera colocar a build numa Vercel/Netlify (grátis) e enviar esse link como "Demo: [LINK]".
